# Crown of the Franks (retired)

This was the development home of **Anointed**. The game has moved to **https://github.com/jdc001/Anointed** and is played at **https://jdc001.github.io/Anointed/**.

The code here is kept as it was at v6.50 for reference; the history continues in the Anointed repository.
